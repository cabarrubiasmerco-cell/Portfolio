TasteTrack — System Architecture & Deep Dive

The Engineering Challenge

Food lovers and amateur chefs need a streamlined platform to document authentic recipes, share culinary tips, and curate favorites. TasteTrack was developed to combine the utility of a cooking cookbook with the community dynamics of a social network.

Key Architectural Highlights

  • MVT Pattern (Model-View-Template): Built on Django 5, dividing concerns between SQLite models, context processor views, and reusable template blocks.
  • Interactive Multi-Reaction Engine: Rather than a generic "like", users can react with 👍 Like, ❤️ Love, or 😋 Delicious. Database constraints (unique_together = ('recipe', 'author')) prevent duplicate reactions while allowing reaction switching.
  • In-App Notifications: Django signals (post_save) dispatch automated alerts to authors when their recipe receives comments or reactions.
  • Profile & Follower Graph: Symmetrical=False Many-to-Many follower relationship, enabling custom social feeds based on followed creators.
Tech Stack Matrix:
Django 5.0 • Python 3 • SQLite3 • Bootstrap 5.3 • JavaScript ES6 • Pillow Image Engine

Relational Model Design (Python / Django ORM)

Here is a snippet from the actual recipes/models.py illustrating the reaction and recipe structures: 

class Recipe(models.Model):
    title = models.CharField(max_length=200)
    description = models.TextField()
    ingredients = models.TextField()
    instructions = models.TextField()
    image = models.ImageField(upload_to='recipe_pics/', blank=True)
    author = models.ForeignKey(User, on_delete=models.CASCADE)
    date_posted = models.DateTimeField(auto_now_add=True)
    prep_time = models.PositiveIntegerField(default=15)
    difficulty = models.CharField(max_length=20, choices=[
        ('Easy', 'Easy'), ('Medium', 'Medium'), ('Hard', 'Hard')
    ], default='Easy')
    repost_of = models.ForeignKey('self', on_delete=models.SET_NULL, null=True, blank=True)

class Reaction(models.Model):
    recipe = models.ForeignKey(Recipe, on_delete=models.CASCADE, related_name='reactions')
    author = models.ForeignKey(User, on_delete=models.CASCADE)
    reaction_type = models.CharField(max_length=2, choices=[
        ('👍', 'Like'), ('❤️', 'Love'), ('😋', 'Delicious')
    ])

    class Meta:
        unique_together = ('recipe', 'author') # Prevents duplicate reactions
